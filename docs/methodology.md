# 分析方法说明

本文档描述 Python 分析层的具体算法。所有统计都在 `backend/app/analytics/` 中完成，LLM 只消费结果。

## 1. 数据清洗与日期归属

WHOOP 的“生理日”（cycle）以入睡为界。为了让“今天”的含义与用户直觉一致：

| 数据 | 归属日期 |
|---|---|
| cycle（Strain） | 本地开始时间 + 8 小时所在日期（23:00 入睡 → 归属第二天） |
| recovery（Recovery / HRV / RHR / SpO₂ / 皮温） | 所属 cycle 的日期 |
| sleep | 醒来时间的本地日期；同一天多段主睡眠合并，小睡单独计入 `nap_minutes` |
| workout | 本地开始时间 − 4 小时所在日期（凌晨 0–4 点的训练算前一天） |

只使用 `score_state == "SCORED"` 的记录。实际睡眠时长 = 浅睡 + 深睡 + REM（不含清醒和无数据时间）。入睡时间存为“距前一个中午 12:00 的小时数”，便于跨午夜比较。

最终每天汇总成 `daily_metrics` 一行，Agent 和页面都优先读这张表。

## 2. 个人基线

对每个指标、每天、每个窗口（7 / 28 / 90 天）计算 **当天之前** 窗口内的：均值、中位数、标准差、P10、P90、样本数（`metric_baselines` 表）。

- 当天不进入自己的基线，避免“今天的异常值稀释了比较对象”
- 最少样本数：7 天窗口 4 天、28 天窗口 10 天、90 天窗口 20 天
- 主比较对象是 **28 日基线**；7 日用于“近期水平”，90 日用于长期背景

单指标分析输出：今日值、近 7 日均值（含今日）、28/90 日基线、相对偏差 `(今日 − 基线) / 基线`、z-score、90 日个人百分位、7/28/90 日线性趋势（斜率、每周变化 %、p 值；p < 0.1 且 |每周变化| ≥ 1.5% 才算“上升/下降”）、连续低于/高于基线天数、连续下降天数、变异系数与“波动加大/减小”。

## 3. 异常检测

规则见 `analytics/anomaly_rules.yaml`，用户可在设置页覆盖（存于 `users.settings.anomaly_rules`）。

**阈值规则**（相对 28 日基线）：HRV 下降 15%、RHR 升高 10%、睡眠减少 15%、Recovery 下降 25%、Strain 增加 30%、呼吸频率升高 6%。

- `fixed` 模式：只看百分比
- `adaptive` 模式（默认）：百分比 **或** |z| ≥ 1.5 都会触发；但如果百分比越线而 |z| < 1（说明在你平时的波动范围内），严重度降为 low
- 严重度 high：偏差 ≥ 2 倍阈值，或 |z| ≥ 2.5

**连续规则**：Recovery 连续 3 天 < 50%；HRV 连续 4 天低于 28 日均值；Strain 连续 3 天高于个人 90 日 P75。

**多指标同步异常**：同一天 ≥ 3 个恢复指标出现“轻度不利信号”（见下节）。

**个性化阈值建议**：对每条规则，取用户历史偏差分布中约 7% 分位处作为建议阈值，并显示当前阈值 / 建议阈值各自的历史触发率。

## 4. 多指标联合分析

先为每个指标判断是否出现“轻度不利信号”（比异常阈值更敏感）：

| 指标 | 百分比阈值 | z 阈值 |
|---|---|---|
| HRV | 低于基线 ≥ 7% | z ≤ −1 |
| RHR | 高于基线 ≥ 5% | z ≥ 1 |
| 睡眠时长 | 低于基线 ≥ 10% | z ≤ −1 |
| Recovery | 低于基线 ≥ 15% | z ≤ −1 |
| 呼吸频率 | 高于基线 ≥ 4% | z ≥ 1.5 |
| 皮肤温度 | 高于基线 ≥ 0.4 °C（绝对值） | z ≥ 1.5 |

满足百分比阈值即为信号；z 越过阈值时，还要求偏差至少达到百分比阈值的一半（避免平时波动极小的人因为极小的绝对变化被标记）。这些阈值同样在 `anomaly_rules.yaml` 的 `signals` 段中可配置。

再结合两个上下文：

- **睡眠偏少**：昨晚比基线少 ≥ max(30 分钟, 8%)，或近 4 天平均少 ≥ 25 分钟，或睡眠负债 ≥ 60 分钟
- **负荷偏高**：昨日 Strain z ≥ 1.3 且高于基线 15%、或高于基线 35%、或近 3 天均值高 20%、或连续 3 天高于个人 P75

状态判定（按顺序）：

| 状态 | 条件 | 训练等级 |
|---|---|---|
| 非训练负荷型异常 | HRV↓ + RHR↑ + (呼吸频率↑ 或 皮温↑)，且负荷不高 | rest |
| 整体恢复状态明显下降 | HRV↓ + RHR↑，相关因素 ≥ 3，且已持续 ≥ 5 天 | recovery |
| 短期恢复不足 | 同上但持续 < 5 天；或 HRV↓ + (RHR↑ 或睡眠少) + 负荷高 | reduce |
| 睡眠相关的恢复下降 | (HRV↓ 或 Recovery↓) + 睡眠少，负荷不高 | reduce |
| 负荷相关的恢复下降 | (HRV↓ 或 Recovery↓) + 负荷高，睡眠正常 | reduce |
| HRV 单项偏低 | 只有 HRV 信号 → **保守：不建议根据单日 HRV 做强判断** | caution |
| 静息心率单项偏高 / Recovery 单项偏低 | 只有该信号 | caution |
| 睡眠偏少但恢复指标暂稳 / 负荷偏高但吸收良好 | 无恢复信号，仅有上下文 | caution / normal |
| 恢复良好 | 无不利信号，且 ≥ 2 项优于基线 | normal |
| 状态平稳 | 其他 | normal |

置信度：28 日基线天数 ≥ 21 且多个信号一致 → 高；基线 ≥ 14 天 → 中；否则低。

所有文案都遵循：**只说“相关因素之一”，不断言因果；多指标下降也不说“你一定过度训练了”；不做医学诊断。**

## 5. 身体状态分（0–100）

```
composite_z = 加权平均(
    HRV z × 0.35,
    −RHR z × 0.25,
    睡眠时长 z × 0.20,
    −max(昨日 Strain z, 0) × 0.12,     # 只计不利一侧
    −max(呼吸频率 z, 0) × 0.08,
)   # 每项截断到 [−3, 3]，缺失项不参与
个人偏差分 = clip(65 + 15 × composite_z, 5, 98)
身体状态分 = 0.4 × WHOOP Recovery + 0.6 × 个人偏差分     # 基线不足时直接用 Recovery
```

等级：≥ 75 良好 · 60–75 正常 · 45–60 偏低 · < 45 明显偏低。

## 6. 个人规律学习

在完整历史上对比“条件成立的日子”与“其他日子”的结果指标：

| 规律 | 条件 → 结果 |
|---|---|
| 短睡眠 | 睡眠 < 6 / 6.5h → 当天 HRV 偏差、RHR 偏差；滞后一天的 HRV |
| 连续高负荷 | 前两天 Strain 都 > 16（样本不足时用个人 P80）→ 当天 Recovery |
| 前日高负荷 | 前一天 Strain > 个人 P80 → HRV 偏差 |
| 长睡眠 | 睡眠 > 7.5h → Recovery ≥ 70% 的比例（Fisher 精确检验） |
| 晚睡 | 00:30 之后入睡 → HRV 偏差 |
| 睡眠一致性 | 一致性 < 70% → Recovery |
| 星期效应 | 某个星期几的 Recovery 相对 28 日均值 |
| 生活事件 | 记忆中带「饮酒 / 熬夜 / 生病 / 压力 / 出差…」标签的日子的次日 → HRV 偏差 |

均值比较使用 Welch t 检验。置信度：样本 ≥ 15 且 p < 0.01 → 高；样本 ≥ 8 且 p < 0.05 → 中；样本 ≥ 5（事件类 ≥ 3）且 p < 0.12 → 低；其余不报告。同时要求效应量超过最小阈值（如 HRV 偏差 4%、Recovery 5 个百分点）。

每次重算都会更新规律；首次出现的日期记为 `first_detected`，周报中展示“本周新发现的规律”（首次导入历史时发现的规律视为已有规律）。

## 7. 历史相似日

特征向量：HRV 偏差、RHR 偏差、睡眠偏差、昨日 Strain z，分别按典型尺度（10% / 5% / 15% / 1）标准化后计算欧氏距离；排除最近 3 天，挑选彼此间隔 ≥ 3 天的最近邻 5 个，报告它们之后 3 天的 Recovery，以及 HRV 回到基线（偏差 ≥ −3%）所需的天数。

## 8. 恢复驱动因素

取近 N 天 Recovery 最好与最差的 25% 日子，比较前置因素（睡眠时长、入睡时间、睡眠一致性、深睡、前日 Strain、前 3 日平均 Strain、前日训练次数）的均值，并计算与 Recovery 的 Spearman 相关（p < 0.05 且 |ρ| ≥ 0.15 视为显著）。
